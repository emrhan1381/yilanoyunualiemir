# Retro Yılan Oyunu (Eski Nesil Klasik Arcade)

Bu proje GitHub Pages ve tarayıcılarda doğrudan çalışacak şekilde tasarlanmış retro tarzda bir yılan oyunudur.

## Özellikler:
- **Eski Nesil Retro Tasarım**: Piksel temalı yazı tipleri, neon yeşil ve koyu temalı nostaljik arcade görünümü.
- **Kişiselleştirilmiş Yılan Karakterleri**: Gönderdiğiniz 5 fotoğraf yılanın baş ve gövde bölümlerine doğrudan gömülmüştür.
- **Kolay Kontroller**: Klavye (Yön Tuşları / WASD) ve Mobil cihazlar için dokunmatik D-Pad.
- **Skor Kaydı**: En yüksek skor yerel hafızada (localStorage) saklanır.

## Nasıl Çalıştırılır?
1. `index.html` dosyasını herhangi bir tarayıcıda (Chrome, Edge, Firefox) açarak doğrudan oynayabilirsiniz.
2. GitHub'da yeni bir repository açıp `index.html` ve `README.md` dosyalarını yükleyerek GitHub Pages üzerinden yayına alabilirsiniz.
