# Kafa Yılanı

Retro görünümlü fotoğraf yemli yılan oyunu.

- Her fotoğraf kafayı yediğinde yılan tam 1 kare (1 br²) uzar.
- Skor, seviye ve kişisel rekor kaydı.
- Klavye (yön tuşları / WASD) ve mobil dokunmatik kontroller.
- Duraklatma, yeniden başlatma ve giderek artan hız.

GitHub Pages için Settings → Pages → Deploy from a branch → main → /(root) seçin.
